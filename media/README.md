# 媒体素材说明

本目录提供面试官无需登录 Coze 即可查看的视觉材料：

| 文件 | 用途 |
| --- | --- |
| `demo-cover.png` / `.svg` | GitHub 首页封面 |
| `workflow-overview.png` / `.svg` | 核心流程与三条分支总览 |
| `coze-mvp-demo.gif` | 6.48 秒循环演示，覆盖推荐、追问和无结果兜底 |
| `demo-storyboard.jpg` | GIF 的静态故事板，便于快速预览 |

`coze-mvp-demo.gif` 使用仓库中的合成输入与公开规则制作，画面已明确注明 **不是 Coze 平台截图**。它负责讲解产品逻辑；真实 Coze 画布和 A–D 原生运行结果单独保存在 [`../evidence/`](../evidence/README.md)，二者不会混淆。

所有素材均不包含账号、头像、工作区、令牌、真实订单或用户信息，并通过 [`../docs/privacy.md`](../docs/privacy.md) 的公开检查。
