# 隐私、数据与公开边界

## 可以公开的内容

- 15 条完全合成的商品记录；
- 工作流节点说明、规则公式、提示词原则与等价配置；
- 由合成数据计算得到的本地示例输入输出；
- 不包含账号信息的工作流画布与运行结果截图；
- 公开演示链接与开源代码链接。

## 不进入本仓库的内容

- Coze、GitHub、OpenAI 或其他服务的令牌、Cookie、密钥与授权文件；
- 真实用户需求、聊天历史、订单、地址、手机号、邮箱或支付信息；
- 本机绝对路径、个人云盘目录、浏览器配置和系统日志；
- Coze 工作区成员、头像、账号 ID、未公开项目列表与余额信息；
- 面试准备、投递策略、个人提示或仅供本人阅读的说明。

## 数据声明

[`../data/products.json`](../data/products.json) 中的品牌、型号、价格、评分、销量、库存、特点与限制均为虚构值。它们只用于演示检索、排序、解释与兜底，不应被当作消费决策、市场研究或真实库存依据。

示例输入是预设测试句，不来自真实用户；`examples/input-output.json` 是本地等价规则的验算结果。`evidence/` 另存真实 Coze 原生试运行截图，两类证据分开标注，均不构成线上交易建议。

## 截图与录屏发布检查

在把任何 Coze 截图、GIF 或视频放入 `evidence/` 或 `media/` 前，逐项确认：

1. 浏览器地址栏、账号头像、邮箱、手机号与私人工作区信息已隐藏；公开作品链接所需的项目 ID 可以保留；
2. 侧边栏没有显示其他私人项目或会话标题；
3. 画面中没有 token、Cookie、环境变量、终端历史或本机路径；
4. 输入只使用本仓库四组固定合成用例；
5. 输出不包含平台自动生成的个人标识；
6. 录屏元数据和文件名不含个人目录信息；
7. 发布前以未登录视角重新检查一次。

## 密钥策略

- `.env*`、密钥文件、会话与日志默认由 `.gitignore` 排除；
- 若未来接入外部 API，只提交 `.env.example`，值使用占位符；
- 任何已提交的真实密钥都必须立即撤销并轮换，删除 Git 历史本身不能代替轮换；
- 公开仓库默认采用最小信息原则：能证明产品能力，但不暴露账号与私人工作区。
