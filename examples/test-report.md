## 数据与证据检查

| 检查 | 结果 |
| --- | --- |
| 商品 ID 唯一，三品类各 5 条 | 通过 |
| 金额只使用 `sample_price` 与“样本价”标签 | 通过 |
| 历史销量/评论为非负数或 `null` | 通过 |
| 四条 `official_current_reference` 均有 HTTPS 官方来源、身份匹配和版本边界 | 通过 |
| 未核实商品不带敏感肌安全断言 | 通过 |
| 避开成分必须明确存在于官方 `formulated_without` | 通过 |
| 严格证据用例不会混入仅标题功效商品 | 通过 |

## 负例

1. 修改推荐的 `sample_price` 后，验证器报与 `daily_rule_v1` 重算不一致；
2. 敏感肌+避开香精时，仅标题写有“舒缓”的面霜被排除；
3. 用户要避开矿物油时，两条倩碧产品线因官方页未在本结构化表中明确列为不添加而被排除；
4. 将平台状态中 `secret_provisioned` 伪改为 `true` 会被验证器拒绝。
