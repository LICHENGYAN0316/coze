# 隐私、密钥与公开边界

## 仓库可公开内容

- 15 条去重与去促销噪声后的日化商品级历史样本；
- 样本价、历史销量和历史评论字段；
- 四条与当前官方产品页可匹配的结构化属性和 URL；
- 工作流等价配置、本地用例、验证脚本与文档；
- 空白 `.env.example`。

## 不公开

- 原始表、完整历史快照、订单表或客户表；
- 姓名、账号、地址、手机号、邮箱、设备标识、支付信息和聊天历史；
- Coze 会话、Cookie、令牌、登录状态或私人工作区信息；
- `ARK_API_KEY` 或任何真实 API 凭证；
- 未脱敏的平台截图或运行日志。

## 数据最小化

`data/products.json` 只保留 MVP 检索和校验所需字段。商品 ID 用于去重与核对；它不与用户、订单或购买行为关联。

历史销量或评论缺失时保留 `null`，不用 0 伪装原始观测；只在排序公式内将缺失值按 0 处理。

## 密钥规则

1. 真实凭证只存在 Coze Secret 或部署平台环境变量；
2. 仓库内只提交空白 `.env.example`；
3. 不在客户端、工作流 JSON、提示词、trace、错误返回或截图中显示密钥；
4. 日志不记录 `Authorization` 请求头；
5. 如密钥泄漏，立即在火山方舟撤销并轮换，再清理 Git 历史。

## 安全与功效表述

- 敏感肌不是通过标题关键词推断；
- 成分“不含”必须有当前官方页面的明确表述；
- 产品线匹配和精确产品+规格匹配分开标记；
- 当前官方配方只是参考版本，最终以手中包装成分表和专业意见为准；
- 不保证个体不会过敏，不输出医疗诊断或治疗建议。

## 截图政策

旧域截图不用于日化版证据。只有在 Coze 画布完成日化同步、配置 Secret 且重新运行 A–D 后，才能新增已脱敏的日化原生截图。截图必须遮罩账号、头像、密钥、私人工作区和无关项目。
